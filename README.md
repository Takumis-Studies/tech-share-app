# TechShare

## アプリの概要

TechShareは、プログラミングや技術に関する記事を投稿・閲覧できる記事共有アプリです。

学習した内容を記事として残し、ほかの人が読める仕組みを目指して制作しました。

## 主な機能

- 記事を一覧で表示する機能
- 記事の詳細をMarkdown形式で表示する機能
- 記事の新規投稿と入力中の表示確認
- 投稿した記事の編集・削除
- ログイン・ログアウトの切り替え
- 題名と本文を対象とした記事検索

## 使用技術と選んだ理由

| 技術 | 使用目的・理由 |
| --- | --- |
| React | 画面を部品ごとに分け、状態の変化に応じて表示を更新するため |
| Vite | Reactの開発環境を簡単に用意するため |
| JavaScript | 記事の取得、投稿、編集、削除などの処理を実装するため |
| React Router | 記事一覧・詳細・投稿画面を切り替えるため |
| react-markdown | Markdownで書いた記事を読みやすく表示するため |
| json-server | 開発中に記事データを保存・取得する仕組みを用意するため |
| CSS | 記事をカード形式にし、見やすい画面に整えるため |

## 工夫した点

記事を入力しながらMarkdownの表示結果を確認できるようにしました。

また、記事をカード形式で表示し、記事の題名や本文を押すことで詳細画面へ移動できるようにしました。

検索機能は `useSearch.js` にまとめ、画面表示の処理と分けています。

## 制作で苦労した点

画面を切り替えた際に、投稿した記事がすぐに一覧へ反映されない問題がありました。

そこで、トップページへ戻った際に記事データを取得し直すように修正しました。

また、ファイルの配置や読み込み先が一致しないことで画面が表示されなくなる問題もあり、エラーを確認しながら修正しました。

## ローカル環境での起動方法

### 1. 必要なもの

- Node.js
- npm

### 2. 必要なライブラリをインストール

```bash
npm install
```

### 3. 記事データ用サーバーを起動

```bash
npx json-server db.json --port 3001
```

### 4. 別の端末で開発用サーバーを起動

```bash
npm run dev
```

### 5. ブラウザで開く

通常は次の住所から利用できます。

`http://localhost:5173`
