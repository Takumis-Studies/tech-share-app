
# TechShare 要件定義書

## 1. アプリの概要

TechShareは、技術に関する記事を投稿・閲覧・検索できる記事共有アプリです。

## 2. 主な機能

1. 記事一覧表示：投稿された記事を一覧で表示する。
2. 記事詳細表示：選択した記事の本文をMarkdown形式で表示する。
3. 記事投稿：ログイン中の利用者が新しい記事を投稿する。
4. 記事編集・削除：記事の投稿者本人が編集・削除できる。
5. ログイン・ログアウト：利用者のログイン状態を切り替える。
6. 記事検索：題名や本文に含まれる言葉で記事を検索する。

## 3. 記事データの項目

| 項目 | 内容 |
| --- | --- |
| id | 記事を識別する番号・文字列 |
| title | 記事の題名 |
| body | 記事の本文 |
| authorId | 投稿者の識別番号 |
| createdAt | 記事の作成日時 |
| updatedAt | 記事の最終更新日時 |

## 4. APIの一覧

| 方法 | 接続先 | 用途 |
| --- | --- | --- |
| GET | /articles | 記事一覧を取得 |
| GET | /articles/:id | 記事詳細を取得 |
| POST | /articles | 新しい記事を投稿 |
| PATCH | /articles/:id | 既存の記事を更新 |
| DELETE | /articles/:id | 記事を削除 |
